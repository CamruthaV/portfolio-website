# Changelog

All notable changes to this project are documented in this file.

This project follows an iterative release model, with each release building upon the previous version.

---

# [v1.2.0] - October 2026

> **V1 — Portfolio release**

Consolidates the features and refinements originally planned across the V1.2 and V1.3 development milestones into the completed portfolio release.

## Added

- Light and dark theme support.
- Interactive project cards with expandable project details.
- Refined professional profile and engineering-focused portfolio content.
- Consistent typography and shared visual design elements.

## Improved

- Responsive layouts and mobile navigation.
- Navigation behaviour and section presentation.
- Card layouts and visual hierarchy across portfolio sections.
- Button styling, spacing, and interaction states.
- Colour consistency across themes and interface components.
- Presentation of certifications, projects, technical blogs, resume, and contact information.

## Release Notes

- Consolidated the original feature milestones into a complete V1 portfolio.
- Retained the existing HTML, CSS, and JavaScript implementation.
- Identified future enhancements as incremental improvements rather than release blockers.
